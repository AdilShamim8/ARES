# Overleaf — Collaborative LaTeX Writing

| | |
|:---|:---|
| **Developer** | Overleaf (Digital Science) |
| **URL** | <https://www.overleaf.com> |
| **Cost** | **Free** personal tier; paid plans add collaborators/track-changes/grammar check |
| **Platform** | Browser-based LaTeX with real-time collaboration and venue templates built in |

## What it covers

Full LaTeX authoring in the browser: venue templates (IEEE, ACM, Springer LNCS, NeurIPS and
thousands more) pre-loaded, real-time multi-author editing, compiled PDF preview, and journal
submission links (many venues accept direct Overleaf submission).

## Why it is recommended here

The *lingua franca* tool of LaTeX publishing: if your target venue is IEEE/ACM/Springer/arXiv
(or any ML conference), you will draft in Overleaf. Its template gallery doubles as a live
reference for venue formats, complementing ARES's `templates/` blueprints.
