# Zotero — Reference Manager

| | |
|:---|:---|
| **Developer** | Digital Scholar (nonprofit) |
| **URL** | <https://www.zotero.org> |
| **Cost** | **Free and open source** (storage beyond 300 MB group-sync has paid tiers; local use unlimited) |
| **Platform** | Mac, Windows, Linux, iOS, Android (the site's current headline advertises Zotero for Android) |
| **Styles** | 9,000+ CSL citation styles (per library guides describing it) |

## What it covers

Per its own description: "a free, easy-to-use tool to help you collect, organize, cite, and
share research" — browser capture, PDF and metadata management, tagging/collections, word-
processor plugins (Word, Google Docs, LibreOffice), BibTeX export, and group libraries. Its
sibling ZoteroBib (<https://zbib.org>) is a free, no-account bibliography generator for
MLA, APA, Chicago, Harvard "and 10000 other styles."

## Why it is recommended here

The default open-source reference manager: free forever, community-governed, no lock-in — and
the citation layer under every serious writing workflow. ARES's citation-mastery skill assumes
a managed library; Zotero is the free way to have one.

## How to use it with ARES

- Collect with the browser connector; export BibTeX to Overleaf ( [`04_overleaf.md`](04_overleaf.md) )
- Run `skills/09_citation_mastery/bibliography_builder.md` over the library to check completeness before submission
- Share a group library with co-authors to avoid "which version of the .bib?" chaos
