# How to use this library

## Mode 0 — the roadmap (the default)

**If you are writing your first paper, do not read this library — *work* it.** Open
[`00_START_HERE.md`](00_START_HERE.md) and follow the 12 steps in order, one
exit test at a time. This is what the library is built around; everything else is support
material for the steps.

## The other reading modes

**Mode A — "I'm writing a section tonight."**

Open [`../07_SECTION_GUIDES/`](../07_SECTION_GUIDES/), read the one file for that section
(they are numbered in manuscript order), watch the matching Ref-n-Write video, and then run the
matching ARES skill. Each section guide lists its video, courses, book chapters by topic, and
ARES pairing in the first ten lines.

**Mode B — "I want a full education."**
Pick the learning path in [`../08_LEARNING_PATHS/`](../08_LEARNING_PATHS/) that matches your
stage (undergraduate → PhD/ECR → specialist paths for non-native English speakers, clinical &
public health, engineering & CS, or the 30-day sprint). Follow it top to bottom; each path names
specific courses, videos, and books with time estimates.

**Mode C — "I need a human to look at my draft."**
Go straight to [`../05_MENTORSHIP/`](../05_MENTORSHIP/). AuthorAID/Rising Scholars offers free
mentoring for researchers in low- and middle-income countries; Grad Coach and The Page Doctor
offer paid coaching; Nature Masterclasses runs live workshops with editor feedback.

**Mode D — "Just give me the software."**
See [`../06_TOOLS/`](../06_TOOLS/) — writing assistants (Ref-n-Write, Paperpal, SciSpace),
LaTeX (Overleaf), and reference management (Zotero), plus a comparison matrix.

## The file anatomy

Every resource profile in this library uses the same structure, so you can scan fast:

1. **Header block** — a table with provider, platform URL, cost, level, format, effort, and the
   *last verified* date.
2. **What it covers** — the real module/unit list (as published by the provider), not a paraphrase.
3. **Why it is recommended here** — the specific strength that earned it a place.
4. **How to use it with ARES** — which ARES skill or evaluator to run alongside.
5. **Pair it with** — cross-references inside this library.
6. **Sources** — the exact URLs checked on 5 November 2026.

## Working with ARES, concretely

| Library step | ARES command |
|:---|:---|
| After you learn Introduction writing | `ACTIVATE: WRITING EXCELLENCE` → `introduction_craft.md` |
| After you learn peer review | `ACTIVATE: QUALITY FORTRESS` → `adversarial_peer_review.md` |
| After you pick a target journal | `ACTIVATE: JOURNAL STRATEGY` → `venue_matcher.md` |
| While building your bibliography | `ACTIVATE: CITATION MASTERY` → `bibliography_builder.md` |

## Conventions

- Prices and ratings are quoted **as displayed on 5 November 2026** and will drift — the profiles
  say where to re-check them.
- "Free to audit" means the learning content is free and only the certificate costs money
  (standard Coursera/edX model).
- Cross-references are relative links, so the library works offline after cloning the repository.
