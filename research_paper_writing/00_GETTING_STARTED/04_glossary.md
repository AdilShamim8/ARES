# Glossary — the working vocabulary of this library

Terms are defined the way this library and the ARES skills use them.

| Term | Working definition |
|:---|:---|
| **AIMRAD / IMRAD** | The standard manuscript architecture: Abstract, Introduction, Methods, Results, and Discussion. Most journals and every guide in this library assumes it. |
| **Abstract** | A self-contained mini-paper (typically 150–300 words, venue-limited) that states background, gap, methods, key results, and implication. |
| **Annotated bibliography** | A source list where each entry carries a short evaluative note; the scaffold of a literature review (taught in UC Irvine's capstone). |
| **Audit (free track)** | Coursera/edX mode where all learning content is free and only the certificate is paid. Most courses here can be audited free. |
| **Cover letter** | The letter to the editor arguing fit and significance; the last gate before review (guide: `../07_SECTION_GUIDES/12_cover_letter.md`). |
| **CRediT** | Contributor Roles Taxonomy — the standard 14-role vocabulary (conceptualization, methodology, writing — original draft…) for author contributions. |
| **DOI** | Digital Object Identifier — the persistent ID for a paper/dataset. ARES treats unresolvable DOIs as critical flaws. |
| **ECA / ECR** | Early-career researcher. |
| **Evidence floor** | ARES rule that every empirical claim must carry a verifiable citation or be flagged. |
| **Gap statement** | The sentence(s) proving a specific unanswered question exists; the hinge between Introduction and your contribution. |
| **Impact factor (JCR)** | Clarivate's mean citations per paper for a journal over two years; refreshed annually (the 2025 release is cited in `SETUP.md`). |
| **Institutional subscription** | Access model where your university pays (e.g., Nature Masterclasses); always check before buying individually. |
| **LMIC** | Low- and middle-income countries — the eligibility frame for free programs like AuthorAID mentoring. |
| **MOOC** | Massive open online course (Coursera, edX). |
| **Peer review** | The pre-publication quality system; learn it from the reviewer side via Nature *Focus on Peer Review* or ACS Reviewer Lab. |
| **Phrasebank** | A bank of ready rhetorical phrases keyed to discourse moves (the Manchester one is free). |
| **Pre-registration** | Time-stamping your analysis plan before data collection (OSF); required by ARES replication workflows. |
| **Predatory journal** | A pay-to-publish outlet mimicking legitimate journals; covered in Stanford Unit 6. |
| **Project-centered course** | A MOOC whose output is a real artifact (e.g., École Polytechnique's course produces an outline, journal choice, and submission checklist). |
| **Research question (RQ)** | The focused, answerable question your study addresses (guide: `../07_SECTION_GUIDES/05_research_questions.md`). |
| **Self-plagiarism** | Reusing your own prior text without citation; an ethics risk covered by MIT 21W.794 and the ethics guides. |
| **Systematic review** | A protocol-driven review (PRISMA-style) rather than a narrative one; supported by ARES `02_literature_command/systematic_review_prompt.md`. |
| **Venue limits** | The per-venue caps (abstract words, page counts) tracked in `templates/` and `SETUP.md`. |
| **Writing assistant (AI)** | Tools like Paperpal/SciSpace that polish or check drafts; ARES itself is the disciplined pipeline above them. |
