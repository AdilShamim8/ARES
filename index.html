ARES — AI Research Excellence System

From raw idea
to published paper.

A complete operating system of prompts, skills, evaluators, and templates that turns an AI assistant into a disciplined research partner for the world's most demanding venues.

Release v3.0· Verified 30 Oct 2026· Engine ARIA v3.1· License MIT· Language plain Markdown· Install 1 paste

ARES is a repository of forty-plus modular documents that take a general-purpose LLM and give it a research editor's discipline: adversarial peer review before submission, quantitative 0–100 scoring gates, venue-exact templates, and a strict evidence floor that refuses fabricated citations. This release re-verifies every dataset, trial identifier, and DOI against live registries — nothing here is remembered, everything was checked.

The ten-station pipeline — say the word, get the deliverable IDEATION → LITERATURE → METHODOLOGY → run your study → DATA → WRITING → QUALITY → JOURNAL → CITATION → IMPACT
§01 · The problem

Why this system exists

Generic LLM prompting produces reviewer bait: shallow summaries, hallucinated citations, boilerplate prose.

Ask an ordinary AI assistant to "help with your paper" and you get a plausible-sounding draft with invented DOIs, generic claims, and none of the falsifiability elite reviewers demand. ARES takes the opposite approach on four fronts:

Epistemic depthvs. summaries
Every skill forces causal depth, falsifiable hypotheses, boundary-condition stress tests, and an anti-summary standard that synthesizes tension instead of listing chronology.
Floornon-negotiable
Adversarial reviewbefore submission
A five-persona panel — Methodologist, Domain Expert, Logician, Communicator, Impact Assessor — attacks the manuscript the way Reviewer 2 will, then a meta-review consolidates the verdict.
5×1reviewers
Quantitative gates0–100 rubrics
Four independent evaluators score the manuscript with weighted dimensions and explicit go/no-go thresholds. No score, no submission.
4engines
Empirical provenancereal-world only
Every example is grounded in verified public datasets, clinical trials, and DOI-registered literature. Fabricated identifiers are classified as critical flaws and eliminated — this release itself corrected six.
100%resolvable

§03 · Start here

Five steps, five minutes, zero setup

No plugins. No install scripts. Just Markdown and one paste.
Step 12 minutes
Get the repository. git clone https://github.com/AdilShamim8/ARES.git — or press Code → Download ZIP on GitHub. No build step; it is all plain text.
download
Step 22 minutes
Install ARIA. Copy the boxed prompt inside MASTER_PROMPT.md and paste it into Claude Project Instructions (recommended) or as the first message of a new chat. This one paste activates the five-step cognitive engine for every reply.
1 paste
Step 31 minute
State your topic. Be specific: "Sample-efficient graph neural networks for drug-target affinity prediction, targeting Nature Machine Intelligence." No topic yet? Ask for a high-novelty question in your field instead.
1 sentence
Step 4on demand
Activate skills like switches. Each command returns one structured deliverable — see the skill table in §05. Example: ACTIVATE: IDEATION returns a gap matrix plus a scored novelty certificate.
10 commands
Step 5iterate
Loop until the gates are green. Run the evaluators, fix what the simulated reviewers found, repeat. The pipeline in the masthead is the recommended order for a full paper.
ship it
Beginner note

If you have never used an AI assistant for research: you do not need to read all 40 files. Read this page top to bottom once, paste one prompt, and start with Step 3. The system will tell you what to do next at every stage.

§06 · The gates

Four quantitative evaluators

Weighted 0–100 rubrics with explicit submission thresholds — a manuscript that cannot pass does not ship.
Novelty Scoreevaluators/NOVELTY_SCORE_RUBRIC
Conceptual (25%), methodological (25%), empirical (20%), translational utility (15%), interdisciplinary synthesis (15%). Top-tier gate for Nature / NeurIPS-grade claims.
≥ 70/100
Rigor Scoreevaluators/RIGOR_RUBRIC
Validity (25%), statistical power & inference (25%), reproducibility & open science (20%), baseline fairness (15%), boundary conditions (15%). Mandatory pre-submission audit.
≥ 75/100
Clarity Scoreevaluators/CLARITY_ANALYZER
Hourglass architecture, paragraph cohesion, cognitive-load economy, visual grammar, terminology precision, abstract calibration — six axes of communication quality.
≥ 80/100
Impact Predictionevaluators/IMPACT_PREDICTOR
24–60-month citation trajectory: theoretical longevity, tool adoption, cross-disciplinary diffusion, translational & policy utility, field-shaping robustness.
≥ 75/100
§07 · The adversarial core

Quality Fortress — peer review before peer review

Accepts LaTeX, PDF, Word, and Markdown. Calibrated on real conference review corpora.

Skill 06 simulates a senior area chair's board: a security scan (prompt-injection defense, double-blind leaks, unicode obfuscation), an 11-dimension technical audit with VLM figure inspection, and a five-persona adversarial panel whose concerns consolidate into one meta-review with a priority-ordered fix list.

Verification policy — how this release was built

DOIs are resolved against doi.org and Crossref; trial IDs against the ClinicalTrials.gov API; database versions against live vendor APIs (ChEMBL 37, PDBbind 2025); journal metrics against the 2025 JCR release. Unregistered identifiers are classified as critical flaws and corrected or removed — v3.0 fixed six of them. Illustrative placeholders inside examples are explicitly labeled so they can never masquerade as real registrations.
